# CBA - Community Budget App

אפליקציית ניהול תקציב לוועד קהילה.

## מבנה

אתר סטטי (HTML / CSS / JavaScript, ללא ספריות חיצוניות), המתארח ב-GitHub Pages.
הנתונים נשמרים ב-Google Sheets, דרך שכבת Google Apps Script שנמצאת בתיקיית `apps-script`.

## מסכים עיקריים

- תכנון מול ביצוע
- ניהול הוצאות
- בניית תקציב
- אזור תושב
