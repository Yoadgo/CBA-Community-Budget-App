## 🟡 כבוי בכוונה — החלטה שלך

**`gardenWriteToFirestore`** — הדפדפן כותב דיווח ישירות ל-Firestore.
הקוד והכללים נבדקו, אבל **לא הרצתי אותו מקצה לקצה בייצור**, כי כדי
לאמת צריך להגיש דיווח אמיתי — וזה יוצר משימה בתור של הצוות ושולח
מיילים לאנשים אמיתיים.

**כשתרצה:** להדליק ממסך "מצב המערכת", להגיש דיווח אחד, ולוודא
שהוא מופיע מיד ושהמייל יצא. אם משהו נשבר — לכבות, והמסלול הישן
חוזר מיד.
